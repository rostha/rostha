# Rostha

**Full-stack web development · Desktop applications**

I build thoughtful interfaces, reliable APIs, and local-first tools. My work connects **React and TypeScript** on the frontend with **Node.js, databases, Tauri, and Rust** behind the scenes.

## Selected projects

### [Vela Board](https://github.com/rostha/vela-board)
A personal task board that keeps its data after the server restarts. Built with **React, TypeScript, Express, and SQLite**.

- Search, priorities, accessible status controls, and JSON export.
- Validated API inputs and version checks that reject conflicting edits.
- HTTP and persistence tests, responsive layouts, and CI.

[Explore the code and run it locally →](https://github.com/rostha/vela-board#try-it-locally)

### [Yuna Notes](https://github.com/rostha/yuna-notes)
A local-first notebook with a **Tauri 2 and Rust** desktop core, **SQLite** storage, and a **React / TypeScript** interface.

- Searchable notes, pinning, Markdown export, and unsaved-change handling.
- A native command boundary with validated inputs and versioned writes.
- Rust persistence tests, a separate working browser preview, and Windows build checks.

[Explore the code and run the app →](https://github.com/rostha/yuna-notes#run-the-desktop-app)
